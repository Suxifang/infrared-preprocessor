# 红外预处理 · Windows 测试版

本地桌面程序，用于示波器 / LabVIEW 的分段红外信号。

本版流程：导入文件或文件夹 → 核对列、峰方向与有效区间 → 基线处理 → 预览 → 导出。
默认反转向下峰；已向上数据可跳过，自动识别在不确定时会停止该文件的处理。
波数标定与拼接尚未接入。

## 直接运行

Windows 10/11 64位：打开发布目录中的“红外预处理.exe”。同目录的内部运行库与开源许可文件请一起保留。
源代码运行：在依赖已安装的Python中执行 app.py。

## 使用

1. 导入 DAT / TXT / CSV / TSV，或直接拖入文件、文件夹。
2. 原始曲线显示后，核对方向。默认反转，已向上的文件改为“已经向上”。
3. 多周期信号应先确定有效区间，可填写数值行号或在图上选区。
4. 计算当前预览。上图是原信号与原极性下的估计背景；下图是校正结果。
5. 如需共用设置，先点击“当前设置应用到勾选文件”，再批量处理。各文件可保留独立设置。
6. 导出勾选结果。DAT与PNG来自同一份计算结果，不会在导出时悄悄重算。
7. 保存项目可保留参数、信号和背景，以后重新打开继续。

列设置在折叠的高级参数中；支持任意选择横轴列与信号列，不固化历史特殊列。
单列输入可自动生成采样行号。裁剪后保留原采样坐标，不重编号。
文件夹扫描默认跳过 outputs、最终交付、处理档案和软件构建目录，避免重复导入处理结果。

## 数值约定

设输入信号为 y，默认反转 s=-1，跳过反转 s=+1。
在 s*y 上估计下包络基线 b，校正值为 s*y-b。
原始信号图上的背景是 s*b，因此可以逐点重建：校正值 = s*(y-原极性背景)。
不裁负值、不默认平滑信号、不归一化，也不把电信号自动称为吸光度。

默认基线库 pybaselines 1.2.1，支持 arPLS、AsLS 与跳过基线。
“背景平滑度”是参考长度1000点时的 log10 λ。开启按点数换算时：

实际 λ = 10^平滑度 × ((有效点数−1)/999)^4

实际参数、算法版本、收敛历史和源文件SHA256保存在处理记录中。
该缩放是可复现的参数约定，不表示任意扫描速度、峰宽的数据都有同一最佳平滑度。
默认方法仍需按本批数据核对，不以宽鼓包消失作为校正正确的证明。

## 输出与限制

每段：两列DAT和原始/基线/校正对照PNG。
每批：处理记录JSON、保存重建数组的NPZ、说明文件。
首版只处理采样坐标或已知时间，基线计算要求所选横坐标近似等间隔。
空值、回跳横坐标不会被自动删除、排序或重采样。
基线未收敛和设置已改但结果未重算的文件不能导出。
宽峰、峰翼与可重复背景可能不能仅凭单条记录区分，预览中的估计背景需核对。

## 开发与验证

基础依赖见 requirements.txt。运行 tests 中的数值验证，执行 app.py --smoke-test 输出目录
可检查真实Qt界面、后台批处理、参数修改后的导出拦截、项目恢复和PNG输出。
开发环境安装 requirements-dev.txt 后，build.ps1 可重新打包；发布时必须保留第三方许可证。
打包配置使用 Infrared.spec，排除与Qt的系统ICU接口不兼容的第三方同名库。
软件本身不调用仪器，也不联网上传测量数据。

## GitHub 与软件更新

代码与发布页：https://github.com/Suxifang/infrared-preprocessor

点击窗口顶部或帮助菜单里的“检查更新”。发现新版后，点击“下载并切换新版”。
软件从本项目发布页读取版本与说明，校验下载大小和SHA256，再解压到本机独立版本目录。
切换前自动保存当前项目；只有新版确认正常打开后，旧窗口才关闭。下载失败、校验失败或
新版启动失败时，当前版本和原始数据保留。处理数据期间可以检查、下载，完成处理后再切换。

更新目录：`%LOCALAPPDATA%/InfraredPreprocessor/versions`。
更新前项目备份：`%LOCALAPPDATA%/InfraredPreprocessor/recovery`。
公开仓库更新无需GitHub账号；网络不通时可稍后重试，或从发布页下载ZIP并解压运行。
本版按需检查更新，不在后台上传实验文件。

发布新版本时先修改 `infrared_desktop/__init__.py` 中的版本与 CHANGELOG.md，
通过测试后推送对应的 `v版本号` 标签。GitHub Actions 会构建、验证并发布测试版ZIP和更新清单。
本地也可运行 `build.ps1`，再运行 `tools/package_release.py` 生成同格式更新包。
